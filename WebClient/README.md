# Massage Platform — หน้าร้าน

Angular 22 application สำหรับงานหน้าร้านนวด เช่น ตารางนัดหมาย บริการ หมอนวด ลูกค้า และสาขา

```powershell
npm install
npm start
```

เปิดใช้งานที่ `http://localhost:4200` ข้อมูลบนหน้าเริ่มต้นเป็นข้อมูลตัวอย่าง ไม่ได้บันทึกหรือเชื่อมต่อกับ API

```powershell
npm test
npm run build
```
